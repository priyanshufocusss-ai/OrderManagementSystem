
# Order Management System

## Project Overview
A menu-driven Java application using JDBC and MySQL to manage customer orders.

## Technologies Used
- Java
- JDBC
- MySQL
- MySQL Connector/J
- Eclipse IDE

## Database
Database: ecommerce_db

Table: Orders

Fields:
- order_id
- customer_name
- product_name
- quantity
- unit_price
- status

## Features
1. Insert at least three orders.
2. Search orders by status and quantity.
3. Increase order quantity.
4. Update order status with validation.
5. Calculate total order value and delete cancelled orders.

## How to Run
1. Create the ecommerce_db database in MySQL.
2. Create the Orders table.
3. Add MySQL Connector/J to the Java project.
4. Update database credentials in the Java source.
5. Run OrderManagement.java.
